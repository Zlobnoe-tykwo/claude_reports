Askona — воронка недели в разрезе сегментов

Неделя 33 · 10–16 августа 2026 vs 11–17 августа 2025 (та же ISO-неделя) · только визиты из страны присутствия магазина · разрез: шаг воронки → новые/вернувшиеся → устройство → канал трафика

Данные — Reporting API Яндекс.Метрики, метрика ym:s:visits, измерения ym:s:trafficSource × ym:s:productEventType (плюс отдельный запрос без productEventType — для стадии «Посетители»), сегментированные по ym:s:isNewUser (новые/вернувшиеся) и ym:s:deviceCategory (ПК/мобайл), с фильтром по стране присутствия магазина (ym:s:regionCountry). Воронка повторяет структуру стандартной e-commerce воронки Метрики: «Посетители» (все визиты сегмента, без привязки к товарным событиям) → «Листинг» (просмотр списка товара) → «Клик по товару» → «Карточка товара» → «Корзина» → «Покупка». Таблица — сворачиваемое дерево, как в самой Метрике: «Итого и средние» → Новые/Вернувшиеся → платформа (Смартфоны/ПК) → канал трафика; стрелка слева от строки разворачивает следующий уровень, по умолчанию видны только «Итого» и Новые/Вернувшиеся. Планшеты и прочие категории устройств в разбивку не включены — это даёт ~1–3% недосчёта визитов по сравнению с общими показателями воронки. Кыргызстан: сравнение не год к году, а к аналогичной неделе месяц назад (13–19 июля 2026) — счётчик пока не проработал полный год, вернёмся к сравнению год к году, когда наберётся история. Каналы с нулевыми значениями по всем стадиям в очередном сегменте не показываются. KPI-карточка «Конверсия (весь трафик)» — Покупка / Посетители по всей стране; столбец таблицы «Конверсия в покупку» — более узкая конверсия внутри канала: Покупка / Листинг (доля тех, кто уже просмотрел листинг), в процентах; подпись под значением — относительное изменение самого показателя конверсии год к году. Блок «Причины отклонений» под таблицами: верхняя строка — авто-подсказка, самый конкретный сегмент (новые/вернувшиеся × платформа × канал), давший наибольший вклад в изменение показателя (это не причина, а сигнал, откуда смотреть); нижняя строка — комментарий аналитика, добавляется вручную.
