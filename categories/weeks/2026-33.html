Askona — воронка недели по товарным категориям

Неделя 33 · 10–16 августа 2026 vs 11–17 августа 2025 (та же ISO-неделя) · только визиты из страны присутствия магазина · разрез: товарная категория → шаг воронки

Прошлые недели:Неделя 33, 2026 (2026-08-10 – 2026-08-16)
Данные — Reporting API Яндекс.Метрики, метрика ym:s:visits, измерения ym:s:productCategoryLevel1 × ym:s:productEventType, с фильтром по стране присутствия магазина (ym:s:regionCountry). В отличие от воронки по сегментам, у категорийной воронки нет стадии «Посетители»: категория товара определяется только с момента просмотра листинга, поэтому воронка начинается сразу с «Листинг» (просмотр списка товара) → «Клик по товару» → «Карточка товара» → «Корзина» → «Покупка». Показаны 11 крупнейших по трафику товарных категорий (фиксированный список, единый для всех стран); все прочие значения ym:s:productCategoryLevel1 (более мелкие подкатегории и локальные варианты названий, не сведённые в общий список) агрегированы в строку «Другое». Локализованные дубли названий категорий (казахские / азербайджанские варианты навигации) по возможности сведены к тому же товарному значению, что и русское название — список известных соответствий ограничен тем, что встретилось в данных на момент сборки, поэтому доля «Другое» может колебаться от недели к неделе при появлении новых локализованных тегов. Строка «Итого» — сумма по ВСЕМ значениям ym:s:productCategoryLevel1, включая «Другое», то есть отражает точный общий трафик, а не только показанные категории. KPI-карточка «Конверсия» — Покупка / Листинг по всем категориям вместе; столбец таблицы «Конверсия» — то же самое отношение для отдельной категории, в процентах; подпись под значением — относительное изменение самого показателя конверсии год к году / к пред. месяцу (см. страну). Кыргызстан: сравнение не год к году, а к аналогичной неделе месяц назад (13–19 июля 2026) — счётчик пока не проработал полный год, вернёмся к сравнению год к году, когда наберётся история. Категории с нулевыми значениями по всем стадиям в очередной стране не показываются. Клик по названию категории раскрывает топ-15 SKU этой категории по текущему трафику в листинге (те же 5 шагов воронки и колонка конверсии, ранжирование — по текущему периоду, прошлогоднее значение SKU показано в скобках, если SKU существовал год назад). Важно: суммы по SKU внутри категории НЕ сводятся к строке самой категории — Яндекс.Метрика логирует событие товарной воронки (в т.ч. «Листинг») отдельно по каждому показанному/просмотренному товару, поэтому один визит, увидевший на странице листинга несколько товаров, засчитывается в каждый из них; сумма по SKU в категории закономерно в несколько раз превышает визит-дедуплицированный итог по категории. Строка «Другое SKU» — сумма всех остальных SKU категории, не входящих в топ-15 (тем же способом подсчёта, тот же эффект пересечения визитов).
