Askona — воронка недели по товарным категориям

Неделя 33 · 10–16 августа 2026 vs 11–17 августа 2025 (та же ISO-неделя) · только визиты из страны присутствия магазина · разрез: товарная категория → шаг воронки

Прошлые недели:Неделя 33, 2026 (2026-08-10 – 2026-08-16)
Данные — Reporting API Яндекс.Метрики, метрика ym:s:visits, измерения ym:s:productCategoryLevel1 × ym:s:productEventType, с фильтром по стране присутствия магазина (ym:s:regionCountry) — то есть у каждой страны свой счётчик Метрики (свой домен) И дополнительный фильтр по гео, так что трафик других стран на том же домене в неё не попадает. Столбец «Посетители» — общее число визитов за период (измерение ym:s:trafficSource, просуммировано по всем каналам, тот же фильтр по стране), заполнен только в строке «Итого»: категория товара определяется лишь с момента просмотра листинга, поэтому для отдельной категории или SKU этот столбец не имеет смысла и показан как «—». Важно: «Листинг» в строке «Итого» может быть БОЛЬШЕ «Посетителей» — это не ошибка, а тот же эффект пересечения визитов, что и у SKU (см. ниже), только на уровень выше: Яндекс.Метрика считает visits уникальными в разрезе каждой отдельной категории, поэтому один визит, за один заход посмотревший листинги двух разных категорий (например, «Матрасы» и «Диваны»), учитывается один раз в каждой из них — при суммировании по всем категориям такие визиты считаются повторно. Поэтому пара «Посетители» / «Листинг» — это не готовый процент конверсии, а два ориентира для одной и той же картины: сколько людей вообще зашло на сайт и насколько активно они смотрели товарные категории. Показаны 11 крупнейших по трафику товарных категорий (фиксированный список, единый для всех стран); все прочие значения ym:s:productCategoryLevel1 (более мелкие подкатегории и локальные варианты названий, не сведённые в общий список) агрегированы в строку «Другое». Локализованные дубли названий категорий (казахские / азербайджанские варианты навигации) по возможности сведены к тому же товарному значению, что и русское название — список известных соответствий ограничен тем, что встретилось в данных на момент сборки, поэтому доля «Другое» может колебаться от недели к неделе при появлении новых локализованных тегов. Строка «Итого» — сумма по ВСЕМ значениям ym:s:productCategoryLevel1, включая «Другое», то есть отражает точный общий трафик, а не только показанные категории. KPI-карточка «Конверсия» — Покупка / Листинг по всем категориям вместе; столбец таблицы «Конверсия» — то же самое отношение для отдельной категории, в процентах; подпись под значением — относительное изменение самого показателя конверсии год к году / к пред. месяцу (см. страну). Кыргызстан: сравнение не год к году, а к аналогичной неделе месяц назад (13–19 июля 2026) — счётчик пока не проработал полный год, вернёмся к сравнению год к году, когда наберётся история. Категории с нулевыми значениями по всем стадиям в очередной стране не показываются. Клик по названию категории раскрывает топ-30 SKU этой категории по текущему трафику в листинге (те же 5 шагов воронки и колонка конверсии, ранжирование — по текущему периоду, прошлогоднее значение SKU показано в скобках, если SKU существовал год назад). Важно: суммы по SKU внутри категории НЕ сводятся к строке самой категории — Яндекс.Метрика логирует событие товарной воронки (в т.ч. «Листинг») отдельно по каждому показанному/просмотренному товару, поэтому один визит, увидевший на странице листинга несколько товаров, засчитывается в каждый из них; сумма по SKU в категории закономерно в несколько раз превышает визит-дедуплицированный итог по категории. Строка «Другое SKU» — сумма всех остальных SKU категории, не входящих в топ-30 (тем же способом подсчёта, тот же эффект пересечения визитов).
